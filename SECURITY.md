# Security reporting

This extension controls browser proxy settings. Please do not publish credentials, cookies, proxy passwords, private network addresses or complete network logs in public issues.

For a potential vulnerability, use GitHub's **Report a vulnerability** option if available. Otherwise contact the repository owner through the contact method listed on their GitHub profile before sharing sensitive details. General bugs and non-sensitive reproductions belong in Issues.

Only the latest published version is maintained. There is no guaranteed response time. The extension does not provide or audit proxy servers, VPN clients or DNS services.

请勿在公开 Issue 中粘贴代理密码、Cookie、私人域名或完整日志。普通功能问题可公开报告，敏感漏洞细节请先联系仓库所有者。
